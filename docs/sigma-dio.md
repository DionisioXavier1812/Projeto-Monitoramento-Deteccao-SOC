# SIGMA-Dio — Operação e Tratativas

## ?? Campos do SIGMA-Dio
- Não atendidos  
- Em espera  
- Deslocamento  
- No local  
- Observação  

## ?? Atalhos
- CTRL + P — Pesquisa  
- CTRL + H — Liberar evento  
- CTRL + M — Meus eventos  
- CTRL + T — Todos os eventos  
- CTRL + E — Encaminhar para espera  
- CTRL + D — Encaminhar para deslocamento  
- CTRL + L — Encaminhar para local  
- CTRL + O — Encaminhar para observação  

## ?? Campo CLIENTES
Consulta de:
- histórico  
- contatos  
- usuários  
- partições  
- zonas  
- eventos  

## ?? Partições
0 — Sistema  
1 — Autoatendimento  
2 — Corredor  
3 — Saguão  
4 — Tesouraria  
5 — Cofre  
6 — Casa forte  
7 — Sala técnica  
8 — Forro/garagem  

## ?? Eventos
- Recebido  
- Código  
- Zona  
- Descrição  
- Via (ETH/GPRS)  
- Movimentações  
- Nota
